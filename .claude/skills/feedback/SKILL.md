# Feedback

1. **Log it.** Add a dated entry at the top of docs/feedback/log.md: the episode and version,
   each point in plain English (translate the owner's words faithfully), and leave a slot for
   the rule each point became.
2. **Distil rules.** For each point, add or update a rule in docs/style/learnings.md under
   today's date: an ID (`L<n>`, next free number), the rule as something checkable, and why.
   Praise becomes a rule too ("keep doing X"). If a point repeats an existing rule, do not
   duplicate it; strengthen the rule and add a line to docs/style/review-checklist.md so the
   self-review catches it next time.
3. **Fill the log slot** with the rule IDs.
4. **Apply.** Change the engine, episode or assets to satisfy the new rules, rebuild, and run
   the QA step and self-review again before showing the new version.
5. **Report back** in one short message: what you understood, which rules you added, what
   changed in the new version.

If a point is unclear, show a small visual option instead of asking a technical question.
